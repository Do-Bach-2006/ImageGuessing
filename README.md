A simple program to help party game

It will be an image guessing game. 2 player will have 1 minute. The image pop ups and the player have to guess
the name of it. The referee will decide whether or not the name is correct. If yes, then the other player have to
guess the name of a new image.

Continue until the one of the clock run out.

step 1: choose the directory that have images for the game
step 2: play

# shortcuts

s : start
r : restart
spacebar : skip image ( with 3 second penalty )
enter : switch between timer
